# 04. Công nghệ nguồn mở được sử dụng

## 4.1. React

- **Phiên bản:** 19.x
- **Giấy phép:** MIT
- **Website:** https://react.dev
- **Mục đích:** Framework giao diện người dùng
- **Lý do chọn:**
  - Component-based, dễ tái sử dụng (bảng, form, modal)
  - Hệ sinh thái lớn, cộng đồng sôi động
  - Quản lý state rõ ràng, hỗ trợ hooks

## 4.2. Vite

- **Phiên bản:** 8.x
- **Giấy phép:** MIT
- **Website:** https://vite.dev
- **Mục đích:** Build tool & dev server
- **Lý do chọn:**
  - Dev server nhanh (HMR)
  - Cấu hình tối giản, dễ mở rộng (React plugin)
  - Build production tối ưu, đóng gói ESModule

## 4.3. Oxlint

- **Phiên bản:** 1.x
- **Giấy phép:** MIT
- **Website:** https://oxc.rs
- **Mục đích:** Lint mã nguồn
- **Lý do chọn:**
  - Tốc độ cao, cài đặt đơn giản
  - Rule hỗ trợ React (rules-of-hooks, only-export-components)
  - Thay thế ESLint tiết kiệm cấu hình

## 4.4. Git / GitHub

- **Giấy phép:** Nhiều giấy phép (Apache-2.0/BSD/OFL)
- **Website:** https://github.com
- **Mục đích:** Quản lý mã nguồn, theo dõi lỗi và phiên bản
- **Lý do chọn:** Theo yêu cầu học phần, hỗ trợ Scrum (issues, projects)
